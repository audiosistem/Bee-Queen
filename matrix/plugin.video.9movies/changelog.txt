v2.5.1
- MOVIE DETAIL PAGE: Renamed the 6 rows to "Find Link", "Trailer",
  "Extras", "Recommended", "Similar To", "Add to Favourites".
  Set the InfoTag title equal to the button label (mediatype='video')
  so Kodi skins display the row's purpose instead of repeating the
  movie title 6 times. Each row also gets its own placeholder icon
  in resources/lib/media/.

v2.5.0
- LINK PICKER LABEL: Replaced movie/show title with quality-tag label,
  e.g. "4K | REMUX | DTS | 5.1 | PixelDrain". Stream parser now extracts
  audio codec (DTS/Atmos/AC3/AAC) and channels (5.1/7.1/2.0) separately.
- DOWNLOADS: New "Download" context menu on each link. Streams the file
  to disk in a background thread with toast notifications on start and
  on completion (size + duration). Existing files prompt before overwrite.
- "My Downloads" top-level menu — lists everything you've downloaded and
  plays them directly. Includes Delete and Open-Folder context items.
- SETTINGS: New Downloads category with a configurable download folder
  (default: special://home/userdata/addon_data/plugin.video.9movies/downloads/).
- MEDIA ICONS: New resources/lib/media/ folder with 46 placeholder PNG icons
  (main menu + every submenu + every genre). Replace any file with your own
  artwork — same filename — and the plugin will pick it up automatically.
