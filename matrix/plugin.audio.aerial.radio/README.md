# Aerial Radio Catalog

**Criador: TrainAgain2**

# Rádio ao vivo, do seu jeito

O **Aerial Radio Catalog** reúne rádios ao vivo numa experiência simples, visual e rápida para Kodi. Escolha uma estação e comece a ouvir, sem passos adicionais.

| Área | O que encontra |
|---|---|
| Favoritos | As suas rádios guardadas para acesso imediato. |
| Mais ouvidas agora | Estações populares para começar imediatamente. |
| Adicionadas recentemente | Descobertas recentes no catálogo. |
| Catálogos temáticos Aerial | Seleções para relaxar, focar, manhã, estrada, noite e treino. |
| Rádios em português | Acesso rápido a rádios de países de língua portuguesa. |
| Buscar por país | Pesquisa por nome do país ou pelo respetivo código. |
| Por país | Exploração de rádios de todo o mundo. |
| Por género / tema | Música, notícias, jazz, rock, eletrónica e mais. |
| Procurar no catálogo | Pesquisa pelo nome de uma rádio. |
| Catálogo offline | Navegação disponível quando precisar de uma alternativa à consulta online. |

## Favoritos

Abra o menu de contexto de qualquer rádio e selecione **Adicionar aos favoritos**. A estação passa a estar disponível no menu **Favoritos**, mesmo depois de fechar o Kodi. Para removê-la, abra o mesmo menu de contexto e selecione **Remover dos favoritos**.

## Instalação

1. Transfira `plugin.audio.aerial.radio-0.5.2.zip` para um local acessível pelo Kodi.
2. Abra **Add-ons** no Kodi e selecione **Instalar a partir de um ficheiro ZIP**.
3. Selecione o ficheiro ZIP e conclua a instalação.
4. Abra **Add-ons → Add-ons de música → Aerial Radio Catalog**.

A ficha do add-on é apresentada automaticamente no idioma selecionado no Kodi. As descrições disponíveis abrangem português do Brasil, português de Portugal, inglês, espanhol, francês, alemão, italiano, russo, chinês simplificado e japonês.

## Compatibilidade

O add-on é compatível com **Kodi 19 Matrix ou posterior**. A disponibilidade de cada rádio pode variar conforme a emissão escolhida.
